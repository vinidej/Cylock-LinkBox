# Cylock LinkBox

**Hub de Links e Recursos de Cibersegurança | Cylock**

## 📌 Sobre o Projeto

O **Cylock LinkBox** é uma proposta de plataforma web destinada à centralização, organização e compartilhamento de links úteis para os membros da **Cylock — Liga Acadêmica de Cibersegurança**.

Atualmente, ferramentas, artigos, repositórios e outros materiais são frequentemente compartilhados em grupos de mensagens, dificultando a recuperação e a consulta posterior dessas informações.

O projeto busca solucionar esse problema por meio de um dashboard web intuitivo, organizado por categorias e acessível em dispositivos desktop e mobile.

> **Status:** Em planejamento — Engenharia de Requisitos e Prototipação UI/UX.
